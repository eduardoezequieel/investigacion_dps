# Investigación DPS - Carrito de Compras (JS)

Proyecto académico: carrito de compras con catálogo de productos, filtros y generación de factura.

## Tecnologías
- HTML
- CSS
- JavaScript (ES Modules)

## Estructura del proyecto
- /css
- /js
  - /data (catálogo / mock data)
  - /services
  - /ui
- index.html

## Cómo ejecutar
1. Descargar o clonar el repositorio.
2. Abrir `index.html` en el navegador.

## Notas
- Los datos del catálogo se encuentran en `js/data/mockData.js`.
- El resto de funcionalidades (UI, carrito, lógica de compra y factura) se agregará en commits posteriores por el equipo.
